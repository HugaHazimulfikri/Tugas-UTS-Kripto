04 Detail Algoritma

🎲 FNV-1a Hash

h = 2166136261
for ch in key:
    h ^= ord(ch)
    h = (h * 16777619) & 0xFFFFFFFF

Menghasilkan seed 32-bit dari kunci string. Distribusi baik untuk variasi kunci kecil.

♞ Warnsdorff's Rule

// Prioritaskan kotak dengan
// tetangga paling sedikit
cands = sorted by degree(q)
for q in cands:
    if dfs(q): return True

Heuristik greedy untuk menemukan Hamilton path. Backtracking digunakan sebagai fallback.

🔄 Dynamic Direction

// Arah berubah tiap karakter
d = (index[output] + j) % 8
// j = nomor karakter ke-n

Arah langkah kuda berubah setiap karakter, membuat cipher bersifat polyalphabetic.
